# نصب دستیار بدون Capacitor و Android Studio

پروژه فقط به‌صورت PWA نگه‌داری می‌شود. برای نصب معمولی، خود Chrome کافی است؛ برای دریافت بسته Android نیز می‌توان از PWABuilder استفاده کرد و نیازی به Gradle، JDK یا Android SDK روی کامپیوتر نیست.

## روش اول: نصب مستقیم PWA

1. فایل `.env` را با تنظیمات Supabase تکمیل کنید.
2. خروجی بگیرید:

   ```bash
   npm ci
   npm run build
   ```

3. پوشه `dist/` را روی یک دامنه HTTPS مانند Vercel، Netlify یا هاست خودتان منتشر کنید.
4. آدرس منتشرشده را در Chrome اندروید باز کنید.
5. دکمه «نصب دستیار روی گوشی» را بزنید؛ یا از منوی Chrome گزینه **Install app / افزودن به صفحه اصلی** را انتخاب کنید.

## روش دوم: ساخت بسته Android آنلاین با PWABuilder

1. ابتدا PWA را طبق مراحل بالا روی یک آدرس عمومی HTTPS منتشر کنید.
2. وارد [PWABuilder](https://www.pwabuilder.com/) شوید.
3. آدرس HTTPS اپ را وارد و **Start** را انتخاب کنید.
4. پس از تحلیل manifest و service worker، بخش **Package for Stores** و سپس **Android** را انتخاب کنید.
5. نام اپ را «دستیار مشاور» و شناسه بسته را `ir.dastyar.crm` قرار دهید.
6. بسته Android را تولید و فایل ZIP خروجی را دانلود کنید. خروجی ارائه‌شده برای تست/نصب و انتشار در Google Play را مطابق توضیحات همان بسته استفاده کنید.
7. signing key و رمز تولیدشده را در محلی امن نگه دارید؛ برای انتشار نسخه‌های بعدی همان برنامه به آن نیاز دارید و نباید آن را در Git قرار دهید.

## حذف نوار مرورگر در بسته Android

PWABuilder فایل Digital Asset Links مورد نیاز را در بسته خروجی ارائه می‌کند. فایل `assetlinks.json` را طبق راهنمای خروجی در مسیر زیر روی همان دامنه قرار دهید:

```text
https://YOUR-DOMAIN/.well-known/assetlinks.json
```

بدون این فایل برنامه همچنان باز می‌شود، اما ممکن است نوار مرورگر نمایش داده شود. پس از انتشار فایل، آدرس بالا باید بدون redirect و با پاسخ موفق قابل مشاهده باشد.

## نکته

PWA و PWABuilder هر دو به یک سایت عمومی HTTPS نیاز دارند. باز کردن `dist/index.html` با `file://`، جایگزین انتشار روی HTTPS نیست و service worker در آن حالت فعال نمی‌شود.
