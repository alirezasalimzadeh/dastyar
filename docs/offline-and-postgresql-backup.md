# حالت آفلاین و پشتیبان PostgreSQL

Supabase مورد استفاده پروژه بر پایه PostgreSQL است. برنامه در حالت آنلاین داده‌های اصلی را برای همان کاربر روی دستگاه ذخیره می‌کند. اگر اینترنت قطع شود، خواندن داده‌های ذخیره‌شده ادامه دارد و ثبت، ویرایش و حذف در صف محلی قرار می‌گیرد. با برگشت اتصال، صف در اولین درخواست جدید با PostgreSQL همگام می‌شود.

## نکات حالت آفلاین

- ورود اولیه و اولین دریافت اطلاعات باید یک‌بار با اینترنت انجام شود.
- داده‌های هر حساب در cache جداگانه نگه‌داری می‌شوند.
- وضعیت «حالت آفلاین» بالای برنامه نمایش داده می‌شود.
- در تعارض ویرایش‌ها، آخرین تغییری که به سرور می‌رسد ملاک خواهد بود.
- فایل‌های عکس حجیم می‌توانند از سهمیه ذخیره‌سازی مرورگر استفاده کنند.
- حذف cache مرورگر یا حذف PWA، نسخه محلی داده‌ها و تغییرات همگام‌نشده را نیز حذف می‌کند.

## پشتیبان JSON داخل برنامه

از مسیر «تنظیمات ← پشتیبان‌گیری» می‌توان همه جداول برنامه، اطلاعات جغرافیایی و پروفایل‌ها را در فایل JSON دانلود یا بازیابی کرد.

## پشتیبان کامل PostgreSQL

روی سیستمی که ابزار `pg_dump` نصب است، Connection string دیتابیس را از تنظیمات Supabase دریافت و بدون ثبت در Git اجرا کنید:

```bash
DATABASE_URL='postgresql://postgres:YOUR_PASSWORD@HOST:5432/postgres' npm run backup:postgres
```

فایل فشرده در پوشه `backups/` ساخته می‌شود. این پوشه و Connection string نباید در Git ثبت شوند.

بازیابی نمونه:

```bash
gunzip -c backups/dastyar-YYYYMMDD-HHMMSS.sql.gz | psql "$DATABASE_URL"
```

## پاک‌سازی اطلاعات

مدیر می‌تواند بعد از دانلود پشتیبان، از همان صفحه «پشتیبان‌گیری» اطلاعات کاری و پروفایل سایر کاربران را پاک کند. حساب فعلی برای جلوگیری از قفل‌شدن ورود و داده‌های جغرافیایی برای کارکرد فرم‌ها باقی می‌مانند. حذف کاربران بخش Authentication فقط با دسترسی مدیریتی Supabase امکان‌پذیر است و عمداً از مرورگر انجام نمی‌شود.
